# 이통사 / 외부 연계 장애 분석
## 절차
1. 내부 요청 생성과 송신 시각을 확인한다.
2. Connection/TLS/Timeout/응답코드를 확인한다.
3. 이통사별·채널별 성공률을 비교한다.
4. 동일 시간대 다른 연계의 정상 여부를 비교한다.
5. 외부 공지/점검과 내부 변경 이력을 확인한다.
6. 내부·네트워크·외부 구간별 근거를 분리해 기록한다.
## 출력
장애 경계, 영향 채널/사업자, 근거, 우회 가능성, Escalation 정보.
