# 발송 실패 분석
## 입력
발생시간, 채널, 요청 ID(비식별), 결과코드, 관련 로그/Metric 요약.
## 절차
1. 요청 수신 여부를 확인한다.
2. Validation/라우팅/Queue 적재 여부를 확인한다.
3. Consumer 처리 및 외부 발송 요청 여부를 확인한다.
4. 이통사 응답과 내부 결과 매핑을 분리한다.
5. 단건/특정 고객/특정 채널/전체 장애인지 범위를 좁힌다.
6. 최근 배포·설정·트래픽 변화와 상관관계를 확인한다.
## 출력
영향 범위, 최초 실패 구간, 근거, 원인 후보, 추가 확인 항목, 임시/근본 조치.
## Human Gate
재처리·운영 변경은 담당자 승인 후 수행한다.
