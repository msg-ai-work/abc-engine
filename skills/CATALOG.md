# Engine Skill Catalog

| Skill | 목적 |
|---|---|
| `domain-core` | Engine 전체 판단 원칙과 공통 체크리스트 |
| `send-failure-analysis` | 발송 실패 구간과 원인 후보 분석 |
| `kafka-lag-diagnosis` | Kafka Consumer Lag/Backlog 진단 |
| `retry-dlq-reprocessing` | Retry/DLQ/재처리 위험 판단 |
| `tps-latency-backpressure` | TPS/Latency/Backpressure 성능 분석 |
| `database-redis-health` | DB/Redis 지연·Lock·Pool 상태 점검 |
| `carrier-integration-incident` | 이통사/외부 연계 장애 구간 분리 |
| `message-state-idempotency` | 상태전이·중복·멱등성 검토 |
| `release-pre-post-check` | 엔진 배포 전후 점검 |
| `observability-log-metric-trace` | 로그·Metric·Trace 관측성 점검 |

각 Skill은 실제 Incident/개발 경험을 반영하여 담당자가 PR로 개선한다.
